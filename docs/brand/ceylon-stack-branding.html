01 — Naming & Positioning

Why "Ceylon Stack"

Two words doing two jobs.

Ceylon is the name the world already trusts this island for — tea, cinnamon, sapphires: goods good enough to export under their own name. It signals origin and quality without needing a slogan, and it reads as trustworthy to a Sri Lankan factory owner who's wary of yet another overseas SaaS logging into their production floor.

Stack is literal: this is genuinely a full technology stack — shop floor sensors, an MES layer, ERPNext at the core, analytics on top — sold and supported as one product, not a single app. It also does double duty as the visual idea behind the mark below: a stack of layers, cut like a gemstone.

Positioning line (for decks, the frontend footer, the pitch): "Ceylon Stack — the smart factory platform for manufacturers who need more than a spreadsheet and less than an SAP rollout."

06 — Voice

How Ceylon Stack talks

Direct, not cute

"Machine down since 14:22" — not "Uh oh, looks like something's wrong!"

Name real things

Job Card, Work Order, OEE — the terms the floor and the ERP both already use. Never invent softer synonyms.

Numbers first

Lead with the figure, then the verdict: "71.4% — below target" reads faster than a sentence explaining it.

No apology copy

Errors say what broke and what to do next. No "Oops!", no exclamation marks on a stoppage.

07 — Applying It

Rollout, in order

1

ERPNext Desk (this week): Website Settings → set App Name to "Ceylon Stack", upload the mark as App Logo + Favicon. This rebrands the login screen and browser tab immediately, no core edit involved.

2

Full Desk color pass: once smart_factory exists, add an app_include_css hook to inject the sapphire/cinnamon tokens into Desk's theme — a supported customization point, not a core edit.

3

Frontend: drop the tokens above straight into apps/frontend's Tailwind/CSS config before any screen gets built, so every component starts on-brand instead of getting retrofitted later.

4

Docs & decks: swap "Smart Factory on ERPNext" for "Ceylon Stack" in the pitch deck and any client-facing doc; keep "Smart Factory on ERPNext" as the internal/technical description where it's useful to be explicit about the stack.
