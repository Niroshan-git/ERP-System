01 — Overview

What Ceylon Stack Is

A business platform for Sri Lankan manufacturers and service businesses, built on ERPNext — open-source, enterprise-grade business software — with a purpose-built client dashboard and a real-time factory floor layer on top.

ERPNext helps a company stay on top of operations: inventory, finance, sales, purchasing, projects, and more — all built in, with no paywalled modules. Ceylon Stack takes that proven core, keeps it completely unmodified, and adds a custom-built client-facing dashboard plus (once the manufacturing layer ships) live machine and shop-floor data — the parts ERPNext doesn't ship out of the box.

Positioning line: "Ceylon Stack — the smart factory platform for manufacturers who need more than a spreadsheet and less than an SAP rollout."

This page documents the product itself — what's actually built and running today, and what's next. For the full market pitch (industries, packaging, go-to-market) see the internal playbook; for brand assets and visual identity see the brand package — both referenced in Changelog & Sources below.

03 — Overview

The Headless Stack

One rule underpins everything below: ERPNext/Frappe core is never modified. Everything custom talks to it only through its REST API.

Shop floor / IoT → MES (mes-service) → ERPNext core (+ custom apps) → Frontend sensors, simulator MQTT → OEE calc unmodified core, Next.js dashboard, (planned) → writes to ERPNext custom DocTypes client-facing UI

Why headless

A client that only calls an API is not a derivative work under GPL-3.0. That's what makes the custom apps and frontend genuinely proprietary, sellable IP — separate from ERPNext's own license.

Repo layout

apps/smart_factory · apps/ceylon_services · apps/mcp-server · apps/mes-service · apps/frontend — one monorepo, one folder per service.

Partial Fulfillment & Copy From Quotation Live

The most recent and most structurally significant piece of the Sales module: real partial-document tracking, plus a SAP B1-style "Copy From" flow for building one Sales Order out of several Quotations.

  • Live
    Multiple partial Sales Orders from one Quotation — accept a Quotation line by line and in partial quantities, using ERPNext's own real remaining-quantity tracking rather than a simplified one-shot copy. A second, different partial order against the same Quotation for the remaining lines is fully supported.
  • Live
    Multiple partial Sales Invoices from one Sales Order — same real remaining-quantity model applied one document later in the chain.
  • Live
    Copy From Quotation — from a new Sales Order, select one or more of the customer's open Quotations (checkbox multi-select), choose which lines and quantities to bring across, and apply them to the order being drafted — the same "Copy From" pattern SAP B1 offers, and a scenario ERPNext doesn't support natively (an ERPNext Sales Order normally links to a single source Quotation). Copied lines carry the real ERPNext linkage back to their source Quotation line, so they show up under that Quotation's own Connections tab and count against its real remaining quantity, the same as a document built the standard way.
  • Live
    Cross-company protection — the Copy From picker only offers Quotations belonging to the Sales Order's own Company, preventing the ERPNext-level validation error a cross-company copy would otherwise cause at save time.

17 — Reference

Licensing (GPL-3.0)

ERPNext is fully open-source under GPL-3.0 — no licensing fees, no locked modules, no vendor lock-in. Because it's GPL-3.0 (not AGPL), the source-disclosure obligation is triggered by distributing a modified copy, not by hosting it as a service — when Ceylon Stack is delivered as hosted SaaS, that obligation is most likely never triggered. The custom layers — the Frappe apps and the frontend — stay proprietary as long as they only ever communicate with ERPNext through its REST API. That's the entire reason the headless architecture in Architecture exists.

"Ceylon Stack is built on ERPNext, a mature open-source ERP used by tens of thousands of companies worldwide — a complete, battle-tested core with no licensing fees and full ownership of the data — with a purpose-built dashboard and factory-floor layer on top that ERPNext doesn't ship out of the box."
